## Summary
วิดีโอนี้ Cole Medin แนะนำเครื่องมือชื่อ **Graphify** ที่ทำงานร่วมกับ **Claude Code** เพื่อสร้างระบบ Local RAG (Retrieval-Augmented Generation) โดยเปลี่ยนข้อมูลในวิกิ (Markdown) ให้กลายเป็น Knowledge Graph
- ช่วยให้ AI สามารถค้นหาข้อมูลที่สัมพันธ์กันได้แม่นยำกว่าการค้นหาแบบ Vector ปกติ
- แก้ปัญหาข้อจำกัดเรื่อง Context Window โดยการเลือกดึงเฉพาะ Node ที่เกี่ยวข้องในระดับ Semantic มาใช้งาน
- ข้อมูลถูกจัดเก็บแบบ Local ทำให้มีความเป็นส่วนตัวและรองรับการขยายตัวของข้อมูล (Scalable)
