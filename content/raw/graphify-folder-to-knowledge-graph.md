- Title: Graphify: Turn Any Folder Into a Queryable Knowledge Graph
- Channel: Cole Medin
- Key Topics: Graphify, Knowledge Graph, Local Intelligence, Semantic Search

## Summary
วิดีโอนี้อธิบายเจาะลึกการทำงานของ **Graphify** ในฐานะเครื่องมือที่เปลี่ยน "โฟลเดอร์ปกติ" ให้กลายเป็น "โครงข่ายความรู้" (Knowledge Graph) ที่ AI สามารถสืบค้นได้
- ระบบจะทำ Indexing ข้อมูลในโฟลเดอร์และระบุความสัมพันธ์ระหว่างไฟล์โดยอัตโนมัติ
- สนับสนุนการสืบค้นแบบ Semantic Query ที่ฉลาดกว่าการค้นหาคำสำคัญทั่วไป
- ข้อมูลถูกประมวลผลและเก็บแบบ Local ทำให้รองรับระบบไฟล์ขนาดใหญ่ได้โดยไม่ต้องเสียพื้นที่ Context Window มหาศาล
