# 🤖 GLM-5.1 Model

## 🌟 Definition
โมเดลภาษาขนาดใหญ่ (LLM) รุ่น Flagship ล่าสุดจาก Z.AI ที่เน้นความสามารถด้าน **Agentic Engineering** และการทำงานผ่าน Terminal โดยเฉพาะ ถูกออกแบบมาให้รับมือกับงานที่ซับซ้อนและยาวนาน (Long-horizon tasks) ได้ดีกว่ารุ่นก่อนหน้า

## 🚀 Key Features
- **Agentic Power:** เก่งกาจในการใช้เครื่องมือ (Tool Use), การเขียนโค้ด และการแก้ปัญหาในระดับ Repository (NL2Repo)
- **Sustainability:** สามารถรักษาความจดจ่อและประสิทธิภาพได้ยาวนาน รองรับการเรียกใช้เครื่องมือได้มากกว่าพันครั้งโดยไม่ Plateaue
- **Terminal Performance:** นำหน้าในด้านการทำงานผ่าน Terminal (Terminal-Bench 2.0)
- **Reasoning Capabilities:** ปรับปรุงด้านการตัดสินใจเมื่อเจอโจทย์ที่คลุมเครือ (Ambiguous problems)

## 🖥️ Local Deployment (Ollama)
- **Format:** สามารถติดตั้งและรันแบบ Local ผ่าน [Ollama Library](https://ollama.com/library/glm-5.1)
- **Requirement:** ต้องการฮาร์ดแวร์ประสิทธิภาพสูง (High-end VPS/GPU) เพื่อให้ทำงานได้ลื่นไหล
- **Privacy:** มอบความเป็นส่วนตัวสูงสุดเนื่องจากข้อมูลไม่ไหลออกจาก VPS

## ⚖️ Comparison (vs. Gemini Flash)
- **Gemini Flash:** เน้นความเร็ว, คุ้มค่าผ่าน API, และเก่งรอบด้าน
- **GLM-5.1:** เน้นงานถึกทน, การแก้ปัญหาทางวิศวกรรมที่ซับซ้อน และทำงานแบบ Offline ได้ 100%
