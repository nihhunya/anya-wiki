# 🔄 Anya Auto-Sync System

**Anya Auto-Sync** เป็นระบบการอัปเดตวิกิอัตโนมัติที่อัญญาพัฒนาขึ้นตามความต้องการของพี่เอิบ เพื่อให้ความรู้ในคลังถูกถ่ายทอดสู่หน้าเว็บ [[llm-wiki-concept|wiki.powpoy.com]] ได้ทันที

## ⚙️ การทำงาน
- เมื่ออัญญาบันทึกข้อมูลใหม่ลงในโฟลเดอร์ `wiki/` ระบบจะ Trigger คำสั่ง Git เพื่อ Push ข้อมูลไปยัง GitHub โดยอัตโนมัติ
- รองรับการทำ [[Publishing-Wiki|Quartz Deployment]] ผ่าน GitHub Actions
